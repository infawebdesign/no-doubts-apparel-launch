## Security and checkout changes

- Server-wide nonce-based Content Security Policy, frame protection, no-sniff, referrer and permissions restrictions. HTML is not cached across CSP nonces. Worker entrypoint corrected so these protections actually execute.
- Prices refresh when the bag opens and before checkout. Checkout compares displayed prices with the live Square catalogue and uses validated catalogue versions.
- Required address review before checkout. This is input validation and customer confirmation, not postal deliverability verification.
- Successful checkout snapshots replace raw names/addresses with a keyed address comparison value. Square retains fulfillment details.
- Hourly maintenance removes abandoned raw snapshots after 24 hours, deletes website checkout cache records after 90 days, cleans expired rate limits, redacts legacy snapshots and verifies Square credentials.
- Background reconciliation checks up to five orders per hourly run, oldest checks first, without relying on a customer return. This is polling, not webhooks; latency increases with order volume. Square Dashboard remains the fulfillment/accounting authority.
- Exact inventory quantities removed from public catalogue responses. Tax/shipping copy corrected. Dependency advisories addressed; Bun audit reported no vulnerabilities.
- Formspree integration remains configured; the previously authorized test was accepted. No additional test email sent in this release.
